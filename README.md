# 🇮🇳 Indian Startup Funding Analysis

##  Project Overview

This project analyzes Indian startup funding data to identify investment trends, popular sectors, leading startups, and investor preferences using Python and data visualization.

## 🎯 Objectives

* Analyze overall startup funding trends.
* Identify top-funded startups and investors.
* Explore sector-wise and city-wise funding.
* Analyze monthly and yearly funding patterns.
* Understand investor preferences and investment stages.
* Explore individual startup funding histories.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Streamlit

## Key Features

* **General Analysis:** Funding trends, sector analysis, city-wise funding, top startups, and funding heatmap.
* **Investor Analysis:** Investment history, preferred sectors, funding stages, and investor comparisons.
* **Startup Analysis:** Company-specific funding history and investment details.

## How to Run

1. Clone this repository.
2. Install the required libraries:

   ```bash
   pip install streamlit pandas matplotlib seaborn
   ```
3. Run the Streamlit application:

   ```bash
   streamlit run streamlit_doc.py
   ```
