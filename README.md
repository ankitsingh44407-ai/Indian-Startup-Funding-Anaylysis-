# 🇮🇳 Indian Startup Funding Analysis

An interactive data analysis dashboard to explore Indian startup funding trends, analyze investor behavior, and understand individual startup funding histories.

🌐 **Live Dashboard:** [Explore the Dashboard](https://india-startup-funding-analysis.streamlit.app/)

## Project Overview...

India's startup ecosystem has experienced significant growth, with businesses attracting funding across different sectors, cities, and investment stages.

This project uses Python and data visualization libraries to explore startup funding data and make funding patterns easier to understand.

The interactive dashboard allows users to analyze funding trends, explore investor activity, and examine startup profiles through visualizations and filters.

## Project Objectives..

* Analyze startup funding trends over time.
* Identify sectors attracting startup investments.
* Explore funding distribution across cities.
* Analyze investor activity and investment patterns.
* Examine individual startup funding histories.
* Present data-driven insights through an interactive dashboard.

## Dashboard Features

### 1. General Analysis

Explore the overall Indian startup funding landscape.

* Analyze funding trends over time.
* Compare monthly funding amounts and deal counts.
* Explore funding distribution across sectors.
* Examine startup funding across cities.
* Identify startups and investors appearing frequently in the dataset.
* Explore relationships and patterns using data visualizations.

### 2. Investor Analysis

Explore investment activity from an investor's perspective.

* Examine recent investments.
* Explore the biggest investments recorded in the dataset.
* Analyze investment distribution across sectors.
* Explore investment patterns across funding stages and cities.
* Examine year-over-year investment trends.
* Discover similar investors based on investment activity.

### 3. Startup Analysis..

Explore individual startup funding profiles.

* Search for a startup and examine its profile.
* Explore its recorded funding history.
* Analyze funding activity over time.
* Discover similar startups using available dataset information.

##  Run the Project Locally

### Prerequisites....

* Python installed on your system
* Git installed on your system

### 1. Clone the repository...

```bash
git clone https://github.com/ankitsingh44407-ai/Indian-Startup-Funding-Anaylysis-.git
```

### 2. Navigate to the project directory...

```bash
cd Indian-Startup-Funding-Anaylysis-
```

### 3. Install dependencies....

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application.....

```bash
streamlit run streamlit_doc.py
```

The application will open in your browser. If it does not open automatically, use the local URL displayed in your terminal.

**Note:** Keep `cleared_data_strmlt` in the same directory as `streamlit_doc.py`, because the application loads the dataset from its project directory.
